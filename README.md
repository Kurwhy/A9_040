# 🎬 Cinema Management App

### Android Cinema Management Application

**Cinema Management App** adalah proyek aplikasi Android berbasis **Kotlin** yang menyediakan antarmuka untuk pengelolaan data bioskop, meliputi film, studio, jadwal penayangan, dan tiket.

Aplikasi ini dikembangkan untuk mempraktikkan pengembangan aplikasi Android, pengelolaan data melalui operasi **CRUD (Create, Read, Update, Delete)**, navigasi antarlayar, serta pembuatan antarmuka pengguna.

---

## ✨ Fitur Utama

| Modul | Fitur |
|---|---|
| 🎞️ Film | Menampilkan, menambah, melihat detail, mengubah, dan menghapus data film |
| 🏢 Studio | Menampilkan, menambah, melihat detail, mengubah, dan menghapus data studio |
| 📅 Penayangan | Mengelola informasi jadwal penayangan film |
| 🎟️ Tiket | Mengelola data tiket melalui formulir dan halaman detail |

## 🛠️ Teknologi yang Digunakan

| Teknologi | Kegunaan |
|---|---|
| Kotlin | Bahasa pemrograman aplikasi Android |
| Android SDK | Pengembangan aplikasi Android |
| Gradle Kotlin DSL | Konfigurasi build dan dependency |
| Android Studio | Lingkungan pengembangan aplikasi |

## 🔄 Alur Pengelolaan Data

Setiap modul menggunakan pola pengelolaan data yang serupa:

```text
Halaman Utama
     |
     +--> Tambah Data
     |
     +--> Lihat Detail
     |
     +--> Ubah Data
     |
     +--> Hapus Data
     |
     +--> Kembali ke Daftar
```

Pola ini digunakan untuk mempermudah navigasi dan memberikan pengalaman penggunaan yang konsisten pada setiap modul.

## 🚀 Instalasi dan Menjalankan Aplikasi

### Persyaratan

- Android Studio.
- Android SDK yang kompatibel dengan proyek.
- JDK yang sesuai dengan konfigurasi Gradle.
- Emulator Android atau perangkat Android fisik.

### 1. Clone Repository

```bash
git clone https://github.com/Kurwhy/A9_040.git
cd A9_040
```

### 2. Buka Project di Android Studio

Pilih **Open**, kemudian arahkan ke folder `A9_040`.

### 3. Sinkronisasi Gradle

Tunggu proses **Gradle Sync** hingga selesai. Pastikan Android SDK dan dependency yang diperlukan tersedia.

### 4. Jalankan Aplikasi

Pilih emulator atau perangkat Android, kemudian klik tombol **Run** di Android Studio.
